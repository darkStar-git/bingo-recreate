Sobre o Projeto


O site foi desenvolvido com o tema Bingo, utilizando as linguagens HTML, CSS e JavaScript. O objetivo principal do projeto foi criar uma página interativa e funcional que simulasse o jogo de bingo de forma simples e intuitiva.
A estrutura do site foi criada em HTML, organizando os elementos principais, como o título, os botões e a área de exibição dos números sorteados. Em seguida, o CSS foi aplicado para definir o design da página, ajustando cores, fontes e posicionamento dos componentes, a fim de proporcionar uma interface visual agradável e harmônica.
O JavaScript foi utilizado para adicionar interatividade ao site, permitindo a geração aleatória dos números e outras funcionalidades dinâmicas. Apesar de sermos iniciantes nessa linguagem, buscamos compreender e aplicar seus conceitos básicos para tornar o projeto mais completo.
Durante o desenvolvimento, enfrentamos alguns desafios técnicos, mas conseguimos superá-los por meio de testes, e revisões constantes no código. O resultado final é um site que representa o aprendizado e a evolução adquiridos ao longo do curso. Estamos satisfeitos com o produto final e esperamos que ele possa ser útil para quem deseja aprender mais sobre desenvolvimento web.
